What is a Design System?

The design system is uniting Kaltura products under the same experience. It provides a common visual language, shared UX patterns and common standards. It helps the design team to scale their design work across all products and maintain consistency.

Getting Started

Atomic Design Approach

The system follows an atomic design methodology — from design tokens (colors, typography) to components (buttons, inputs) to full page templates.

Getting Started

DS Documentation

The design system guidelines are documented and maintained. The documentation serves product designers, developers, QA engineers, and product owners — each able to reference, reuse, and contribute to the system.

Style

Iconography

Icons symbolize concepts and actions in a graphic form. They are designed on 16px and 24px pixel grids with 2px stroke, 2px corner radius, and 1px caps. Icons scale with consistent factors to ensure alignment.

Style

Elevation

Elevation is the depth relation of all surfaces. Every element has its corresponding location along the z-index. Elevation is depicted with shadow that reflects the distance between surfaces.

Illustration

Illustrations are structured using primary shapes. Subjects are created by adding and subtracting geometric shapes. They use the Kaltura brand colors: Royal Blue (#006EFA), Red (#FA374B), Yellow (#FFCD00), with black and white.

Components

Action Buttons

Buttons allow users to take actions with a click. They are displayed in different sizes, colors and styles. Available in Pill and Borderless variants, with Primary, Secondary, Danger, and Translucent colors.

Sizes

Small, Medium, Large, XL

Variants

Pill (has a background) and Borderless (background highlights on hover).

Content

Text, Text + Left icon, Text + Right icon, Icon only.

States

Default, Hover, Processing, Disable.

Components

Circular Button

Circular button is typically used for special actions. Available in Small, Medium, and Large sizes with Default, Hover, Focus/Active, and Disable states.

Components

Links

Links come in Small and Large sizes with states: Default, Hover, Active, Disable, and Visited. When found in body text, the link inherits the font size and should be underlined. Also available in Translucent mode.

Components

Select Button

Select buttons open menus. Available in Outline and Borderless variants with Text, Text + Icon, and Icon + Icon content options. States: Default, Hover, Focus, Disable.

Components

Input Text Fields

Input text fields come in Single Line and Textarea types, in Medium and Large sizes. Available in Light and Translucent modes with full state coverage: Default, Hover, Focus, Error, Processing, Disable.

Components

Menu

A menu displays a floating surface containing a list of options or settings. It can be triggered from a select button or any action button. Supports Select Menu, Action Menu, and second-level menus.

Components

Autocomplete

The autocomplete is a text input enhanced by a menu of suggested options. Includes overflow/truncation behavior and a no-results state.

Components

Date & Time Picker

Date and time pickers allow selecting a specific date/time or a time period. The date can be selected via the calendar or edited in the text input field. Only digits are accepted; invalid input resets to the initial value.

Components

Tabs

Tabs organize content into separate views. Users can switch between views by selecting a tab.

Components

Segmented Control

Segmented controls allow users to switch between a set of mutually exclusive options displayed as a button group.

Components

Data Table

Data tables display information in a structured grid format with rows and columns. Supports sorting, selection, pagination, and various cell types.

Components

Cards

A card is a flexible-size container representing a single subject with information and actions. Each card follows a structure including an image area, details, and actions. Cards can be displayed in grid or stacked layouts.

Components

Modal

Modals sit on top of the main content with a backdrop layer. They focus user attention on a specific task or information that requires interaction before returning to the main interface.

Components

Acknowledgment

Acknowledgment components communicate messages to users or provide feedback. Available in Success, Error, Warning, and Info variants.

Components

Hint

Hints provide contextual information or guidance through positioned tooltips. Available in top, bottom, left, and right positions.

Components

Breadcrumb

Breadcrumbs show the user's current location within a navigation hierarchy, allowing easy navigation back to parent levels.

Components

Chips & Tags

Chips and tags are compact elements that represent an input, attribute, or action. They can be removable and support various states.

Components

User Picture

User picture components display avatars in different sizes and shapes (square/round). They support images or initials as fallback.

Components

Tree View

Tree view displays hierarchical data in an expandable/collapsible structure, allowing users to navigate nested content.

Components

Color Picker

The color picker allows users to select a color value from a visual interface with support for custom hex input.

Components

Slider

Sliders allow users to select a value or range from a continuous or discrete set of values by moving a handle along a track.

Components

Loading & Processing

Progress and processing indicators are visual indications while the app is loading content or performing actions. Includes skeleton loading states (alternating opacity 0.5 to 1 every second) and processing spinners for buttons/inputs.

Components

Keyboard Focus Outline

Keyboard focus outlines provide visible indicators for keyboard navigation, ensuring accessibility for all users.

Components

Title

Title components for section headings and page titles.
